## Review rounds

- **Round 1** (five reviewers: leader safety, Kubernetes semantics, Autumn integration, tests and spec with mutation testing, security and docs). High findings: the task supervisor spun after the elector died; config was ignored in Docker images. Medium findings: a starved elector kept a stale "leading"; old tasks could overlap a new leader; a renew removed Lease metadata; any Lease name could be created; the shutdown hook could be dropped before release; kube error text could leak credentials; a bad kubeconfig ran detached. All fixed, with a test first.
- **Round 2** (two reviewers on the round-1 diff). A dropped runtime freed the lease while tasks ran; the manifests example used the dev profile (16 s grace period); a health request could wait for two probes; six weak tests (mutants survived); more `scrub` forms. All fixed; each new test kills its mutant.
- **CI** found two more: example binaries under `cargo llvm-cov`, and a lost create race counted as an error. Both reproduced locally and fixed.
- **Round 3** (one reviewer on the round-2 diff): no high or medium findings. Six low findings, all fixed in a follow-up PR with tests: an empty `--profile` passed the manifests guard; more `scrub` forms (`Basic`, quoted `Bearer`, key case); a mistyped `KUBECONFIG` ran detached; the `api_up` metric could be 10 s old; `.env` read errors lost their text; two counts in this file. Review stops here (limit: 3 rounds).
